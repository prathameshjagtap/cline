2. NarrationEventBus Internal Flow

Decision logic inside the event bus — debouncing, batching, priority handling, and TTS routing.

flowchart TD
	EVENT["Incoming NarrationEvent"] --> ENABLED{"narrationEnabled?"}
	ENABLED -- No --> DROP["Drop event"]
	ENABLED -- Yes --> PARTIAL{"partial?"}
	PARTIAL -- Yes --> DROP2["Skip (streaming)"]
	PARTIAL -- No --> PRIORITY{"High priority?\n(error / completion)"}
	PRIORITY -- Yes --> FLUSH["Flush pending queue"] --> SYNTH_HP["synthesizeNarration()"] --> PROCESS["processAndBroadcast()"]
	PRIORITY -- No --> ENQUEUE["Add to pendingEvents"] --> DEBOUNCE["Schedule drain (200ms)"]

	DEBOUNCE --> DRAIN["drain()"]
	DRAIN --> FILEOP{"File operation?"}
	FILEOP -- Yes --> BATCH["Accumulate file ops\n(batchFileOps)"]
	FILEOP -- No --> REASONING{"Reasoning event +\nsummarization enabled +\nAPI key present?"}
	REASONING -- Yes --> SUMMARIZE["ReasoningSummarizer\n(gpt-4o-mini)"]
	REASONING -- No --> SYNTH_N["synthesizeNarration()\n(template-based)"]
	SUMMARIZE --> COMBINE["Combine narrations\nwith '. ' separator"]
	SYNTH_N --> COMBINE
	BATCH --> COMBINE
	COMBINE --> PROCESS

	PROCESS --> PROVIDER{"narrationProvider?"}
	PROVIDER -- "browser" --> BROADCAST_TEXT["broadcast(text)"]
	PROVIDER -- "openai" --> OPENAI_TTS["synthesizeSpeechOpenAi()"] --> BROADCAST_AUDIO["broadcast(text, audioBase64, audioFormat)"]
	OPENAI_TTS -. "on failure" .-> BROADCAST_TEXT

5. TTS Playback — Dual-Mode Architecture

Two playback paths: browser-native (free, local) and OpenAI cloud TTS (paid, high-quality).

flowchart TD
	NARRATION["Narration text ready"]

	NARRATION --> MODE{"narrationProvider\nsetting"}

	MODE -- "'browser'" --> GRPC_TEXT["gRPC stream:\n{text, interrupt}"]
	GRPC_TEXT --> WEBSPEECH["Web Speech API\n(SpeechSynthesisUtterance)"]
	WEBSPEECH --> SPEAKER1["🔊 VS Code Webview"]

	MODE -- "'openai'" --> OPENAI["OpenAI TTS API\nPOST /v1/audio/speech\nmodel: tts-1, voice: nova\nformat: AAC"]
	OPENAI --> GRPC_AUDIO["gRPC stream:\n{text, audioBase64, audioFormat}"]
	GRPC_AUDIO --> AUDIO_EL["HTMLAudioElement\ndata:audio/aac;base64,..."]
	AUDIO_EL --> SPEAKER2["🔊 VS Code Webview"]

	OPENAI -. "API failure" .-> GRPC_TEXT

	MODE -- "CLI (callback)" --> CLI_CB["registerNarrationCallback"]
	CLI_CB --> PLATFORM{"process.platform"}
	PLATFORM -- "darwin" --> SAY_CMD["say command"]
	PLATFORM -- "linux" --> ESPEAK["espeak / espeak-ng"]
	PLATFORM -- "win32" --> PWSH["PowerShell\nSpeechSynthesizer"]
	SAY_CMD --> SPEAKER3["🔊 Terminal"]
	ESPEAK --> SPEAKER3
	PWSH --> SPEAKER3

6. Sequence — Full Lifecycle

A typical narration flow when Cline reads and edits a file.

sequenceDiagram
	participant Task as Task Engine
	participant Bus as NarrationEventBus
	participant Synth as Synthesizer
	participant TTS as OpenAI TTS (optional)
	participant Transport as gRPC / Callback
	participant Player as NarrationPlayer

	Note over Task: Cline starts working on a task

	Task->>Bus: emit({say:"reasoning", text:"...", partial:true})
	Bus-->>Bus: Skip (partial=true)

	Task->>Bus: emit({say:"reasoning", text:"full text", partial:false})
	Bus->>Bus: Enqueue + schedule drain (200ms)

	Task->>Bus: emit({say:"tool", text:'{"tool":"readFile","path":"src/main.ts"}'})
	Bus->>Bus: Enqueue (file op detected)

	Task->>Bus: emit({say:"tool", text:'{"tool":"editedExistingFile","path":"src/main.ts"}'})
	Bus->>Bus: Enqueue (file op detected)

	Note over Bus: 200ms debounce expires

	Bus->>Synth: synthesizeNarration(reasoning event)
	Synth-->>Bus: "Thinking about the approach."

	Bus->>Bus: batchFileOps([readFile, editedExistingFile])
	Bus-->>Bus: "Reading main.ts. Editing main.ts"

	Bus->>Bus: Combine: "Thinking about the approach. Reading main.ts. Editing main.ts"

	alt Provider = "openai"
		Bus->>TTS: synthesizeSpeechOpenAi(combined text)
		TTS-->>Bus: base64 AAC audio
		Bus->>Transport: sendNarrationEvent(text, audio)
	else Provider = "browser"
		Bus->>Transport: sendNarrationEvent(text only)
	end

	Transport->>Player: NarrationTextEvent
	Player->>Player: speak(text) or playAudio(base64)

	Note over Task: Task completes

	Task->>Bus: emit({say:"completion_result"})
	Bus->>Bus: HIGH PRIORITY → flush + skip debounce
	Bus->>Synth: synthesizeNarration()
	Synth-->>Bus: "I've finished the task."
	Bus->>Transport: sendNarrationEvent(text, interrupt=true)
	Transport->>Player: interrupt + speak
